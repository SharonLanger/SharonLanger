# Profile icons

`data/icons.json` is the index for these SVG files. The build embeds them in the generated profile graphics.

- Python, TypeScript, Node.js, and LinkedIn are from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0), under the [Devicon MIT license](LICENSE-devicon.txt).
- Docker and GitHub are from [Pixelarticons](https://github.com/halfmage/pixelarticons), under the [Pixelarticons MIT license](LICENSE-pixelarticons.txt). The icons use fixed colors for contrast on the profile badges.
- Project symbols, tag illustrations, the book, envelope, fallback code mark, and check mark are maintained with this profile. Tag illustrations can be replaced individually through the catalog.
