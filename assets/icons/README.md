# Profile icons

`data/icons.json` is the index for these SVG files. The build embeds them in the generated profile graphics.

- LinkedIn is from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0), under the [Devicon MIT license](LICENSE-devicon.txt).
- Docker and GitHub are from [Pixelarticons](https://github.com/halfmage/pixelarticons), under the [Pixelarticons MIT license](LICENSE-pixelarticons.txt). The icons use fixed colors for contrast on the profile badges.
- The other Tech & Tools icons are drawn on 12 × 12 grids for this profile. Project symbols, other tag illustrations, the book, envelope, fallback code mark, and check mark are also maintained here. Icons can be replaced individually through the catalog.
